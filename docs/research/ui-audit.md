# Tuck UI audit

Date: 2026-11-03. Branch `feat/clean-media-idle-ui` @ 6f4520e. Read-only audit; no source changed.
Screenshots: `docs/research/screens/` (generated by `docs/research/shoot.mjs` against `dist/` in browser demo mode, 560x260 @2x, Edge). `bun run build` succeeds.

Caveats: browser demo has no native data, so lyrics, stats, clipboard, dictation and visualizer show their "unavailable" states, and the demo banner (`main.ts:860-868`) overlaps the top-right of every open page. Screens were not captured with real artwork, so the `--art-wash` bottom glow is not shown.

### 3.2 Jank risks, ranked

1. **Layout-driven shell morph with live content.** Width + height transitions force relayout of the entire `.full` tree (10 pages are in the DOM, only the current one is `display:flex` so relayout is bounded, but the lyrics pane, `mask-image` list, and `scrollTop` recalculation in `updatePosition` are included). Prefer: fix `.full` at final 500x210, clip it with `overflow:hidden` on the island (`clip-path`/`border-radius`), and animate the shell with `clip-path` or `transform: scale` plus counter-scaling for the pill; or accept width/height but isolate with `contain: layout paint` on `.full` and `.compact`.
2. **`filter: blur(8px)` transition on `.full`** (`styles.css:305-316`): GPU cost and a visible blur frame, on every open and close.
3. **Hard cut compact content** plus 1s/200ms `innerHTML` rewrites resetting animations (`main.ts:409,596`).
4. **Page transitions with no exit and rebuilt dots**, so a rapid wheel sequence (350ms lock) shows overlapping 320ms animations only on the incoming side.
5. **Looping layout animation** (`eq` height) running in idle with nothing playing.
6. **Island `box-shadow` repaint** while resizing.
7. `mask-image` + `overflow-y:auto` on `.lyric-lines` with `scrollTop` jumps (no smooth scroll to the active line: `lyricList.scrollTop = ...`, `live-ui.ts:70`), so lyrics snap line-to-line.
8. `will-change: width, height, border-radius` permanently on: promotes nothing useful for layout props and holds a layer.

### 3.3 Missing transitions

- Content cross-fade inside the compact pill (idle ↔ media ↔ timer ↔ announcement).
- Shared-element morph between compact artwork (`.mini-art` 20px) and the open artwork (52px). Today the compact layer fades out and the open layer fades in with no relationship.
- Morph between activities: a timer starting while media plays swaps the pill content instantly; the compact timer → open timer page has no continuity (digits could move from the pill to the page's digits).
- Page-to-page: outgoing fade/slide, plus vertical morph for the usage list.
- Track change: title/artist/artwork cut instantly (`renderMedia`, `main.ts:363-372`); artwork `background-image` swaps with no crossfade; accent/`--art-wash` change snaps (`--accent` has no `transition` because it is a custom property; use `@property` or two stacked layers).
- Play/pause icon swap (`innerHTML`, `main.ts:376`): no morph.
- Lyric active line: color transition only (.18s), no scale or position easing.
- Value changes: percentages (`62%` → `64%`), battery, timer digits all hard-set. A number tween is the one change explicitly "explaining something".
- Open/close asymmetry: close should be quicker than open (DESIGN.md says 340ms vs 560ms; code uses the same).
- Announcement enter/exit: pill grows to `peek` and content hard-cuts.

### 4.2 Passes that matter most for this app (skill order)

1. Spacing: move everything to the 4px scale, define tokens (`--s-1..`) and remove 3/5/6/7/10px.
2. Color: tokenise `--ok`, `--warn`, `--caution` (amber), decide whether the art-wash applies at idle.
3. Icons: switch to one stroked 1.5/16-18px set, or at least one fill size per context (14 compact / 20 controls).
4. Copy: drop periods, drop the header date/time row, make empty states one line.
5. Type: weights 400/500 (600 for title only), one numeric format (24h or 12h), one date format.
6. Layout: remove nav arrows, rebalance media page, cut the page count by grouping.
7. Details: 4 button radii → 1 (`8`), focus ring consistency.
8. Visuals: art-wash only while playing; the `eq` only when audio is measured active.
9. Motion: one curve, 3 durations (120/200/360), transform/opacity only.

## 6. Top 10 problems

1. **Ten pages, ten dots, two always-on arrow buttons.** Navigation is the most prominent chrome (`styles.css:319-346`, `main.ts:238-252`); the arrows eat the vertical middle of every page and duplicate wheel/keys. Group pages and replace arrows with swipe/hover edges.
2. **Idle notch cannot hold its own content.** 212px holds a 22px icon + 190px text + eq; with media active the note glyph overlaps the title (`01-idle.png`); eq runs constantly in idle even with nothing playing (`main.ts:510`).
3. **Media header is clutter.** Date, time, battery bolt, and eq above the title, and the time clips at the eq (`03-open-media.png`). Date/time exist on Today and idle already.
4. **Text where graphics belong.** `62%` labels + bars (usage), `82%` + bar (today/compact), status pill `Ready/Active/Paused`, stats `Unavailable`/`45% · 6.2 GB / 16 GB`, `Live · 14:02:11` strings; no progress rings or status dots anywhere, although timer/usage already carry the numeric progress.
5. **Activities page is 6 text buttons.** `5m 15m 25m Focus Stopwatch Pause Reset` occupy ~2/3 of the page. Ring + digits + gestures (scroll to set, click to start/pause) would remove four buttons.
6. **Shell morph animates `width`/`height` over a live, blurred content layer** (`styles.css:101-136,301-317`): layout every frame, `filter: blur(8px)` on `.full`, always-on `will-change`, and a shadow repaint; content is visible mid-resize.
7. **No continuity between states.** Compact content hard-cuts (`innerHTML` rewrites every 200ms/1s, restarting eq), pages swap with only an incoming slide, dots are rebuilt so their width transition never runs, artwork/accent/play-pause/numbers snap. No morph between compact and open artwork or timer.
8. **Spacing, weight, radius, and icon-size systems are ad hoc.** 2/3/5/6/7/10px steps, weights 300/500/600/700, button radii 6/7/8/10/14, icon sizes 14/18/20/22/26, 12 distinct durations, overridden duplicate rules (`styles.css:921-931`, `live.css:117-145`).
9. **Inconsistent time/date formats and copy.** 12-hour on Today vs 24-hour on idle/media; three different date formats; trailing periods and prose empty states throughout; `Windows settings and screen snip · Tuck settings` footnote.
10. **Looping and decorative effects, plus reduced-motion gaps.** `eq` height keyframes forever, pulsing timer icon, green bolt circle as the loudest idle element, hue gradient on the whole shell including idle, and reduced-motion `visibility:hidden` on spectrums instead of a calm alternative. Also doc drift (DESIGN.md says 440x180 with 560ms overshoot; code is 500x210, 380ms monotonic) means no source of truth for the geometry or motion.
