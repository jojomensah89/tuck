# Support

Start with the [README](README.md) and [releasing guide](docs/releasing.md). Search existing [issues](https://github.com/jojomensah89/tuck/issues) before opening a bug report or feature request. Include your Tuck version, Windows version, and steps to reproduce. Remove private data from attachments. Community support has no guaranteed response time. Send security reports through [private reporting](SECURITY.md).
