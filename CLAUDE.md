# Working on Tuck

Read `DESIGN.md` before changing any UI.

## No explainer text

Never add descriptive or explanatory text to the UI: no grey description line under a setting's title, no note above a group or panel, no tagline, no hint. A row is its title and its control.

Text under a title is allowed only for:
- an error,
- a live status that changes (download progress, update status, the dictation device line),
- data, such as a model's size.

If a setting seems to need a sentence, rename it or change the control instead. The owner removed every such line on 2026-11-11; do not add them back. Reviews should flag any new one.
